# 文档目录

- `product/`：产品文档，包括 PRD、PDD 等描述产品当前形态的文档。
- `technical/`：技术文档，包括 Tech Spec 等描述技术设计与实现约束的文档。
- `iterations/`：迭代记录，说明每次迭代的原因、修改内容和新增内容。
- `使用说明.md`：面向使用者的操作说明。

## 迭代记录约定

现有记录：

- [2026-09-09：第一版——求职分析与学习计划 MVP](iterations/2026-09-09-第一版-求职分析与学习计划-MVP.md)

每次产品迭代在 `iterations/` 中新增一份独立文档，至少记录：

1. 为什么进行这次迭代；
2. 修改了什么；
3. 增加了什么。

文件名建议使用 `YYYY-MM-DD-迭代主题.md`，便于按时间回顾产品演化过程。
